# CoverageFit v3.15 Release Highlights

## A consultation platform, not a quote form

CoverageFit v3.15 introduces a production-ready Agent Workspace that converts customer assessment information into an organized insurance consultation.

## What is new

- A complete producer-facing Workspace
- A structured Conversation Planner and synchronized timeline
- A persistent consultation checklist
- Live progress and remaining-time guidance
- Professional loading, empty, error, and recovery states
- Keyboard, screen-reader, reduced-motion, high-contrast, mobile, tablet, and ultrawide support
- Render and lifecycle performance safeguards
- Static-host deployment configuration
- Frozen API and persistence compatibility baseline
- Comprehensive automated regression coverage

## What remains unchanged

- CoverageFit remains educational and review-first.
- Recommendations identify topics to discuss, not products to buy.
- Customer assessments, scoring, recommendation rules, and reports remain separate from the Agent Workspace operational layer.

## Release status

The v3.15 line is the first stable Agent Workspace platform baseline. Future Workspace modules should extend this architecture rather than fork or replace it.
