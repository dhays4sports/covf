# CoverageFit v1.2 Trigger Illustrations

Implemented a trigger-aware visual system using one persisted trigger value.

## Visuals
- homebuyer: house, moving boxes, key
- renewal: calendar, shield, checklist
- premium-increase: policy, rising line, magnifying glass
- default: home and shield

## Integrated surfaces
- Trigger landing pages
- Assessment
- Report-generation experience
- Protection Snapshot cover
- Booking page

## Shared assets
- `/assets/js/trigger-illustrations.js`
- `/assets/css/trigger-illustrations.css`
- `/assets/illustrations/*.svg`

The query parameter remains the source of truth and is persisted in `sessionStorage`.
